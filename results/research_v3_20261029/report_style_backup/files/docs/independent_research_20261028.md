# Независимая исследовательская рецензия ASTC-KV

Дата проверки: 2026-10-28. Область: первичные публикации, актуальные исходники ближайших реализаций, контракт следующего численного опыта. Применён `architecture-review`. Это отдельная проверка источников и постановки; аппаратные результаты других авторов здесь не воспроизводились. Исходный обзор v0.1 и старые результаты сохранены.

## Вердикт

Полезная узкая гипотеза остаётся: валидные ASTC-блоки могут быть постоянным представлением активного KV, если текстурное чтение внутри attention вместе с обновлением страниц даст полезный результат против хорошего low-bit runtime. Ни scalar ASTC, ни перенос кодировщика, ни per-token V, ни исправление среднего смещения сами по себе не устанавливают новизну.

Предыдущий обзор правильно отделяет ASTC-веса Apple, восстановление видеокодеками и прямое low-bit attention. Но обзор неполон в части коррекции ошибки и структурного остатка. Добавлены три релевантных источника ниже. Сохранённые science/records уже использованы: новый алгоритм на них нельзя считать независимо подтверждённым.

Главный риск сравнения — объявить успехом небольшую экономию только V при FP16 K либо ускорение относительно неудовлетворительного reference. Минимальные альтернативы: (1) оставить ASTC V-only как диагностический контроль; (2) сравнить U4 K + ASTC V против U4 K+V при общей точности; (3) остановить именно текущий ASTC-формат, если качественный low-bit путь его доминирует. Переход к быстрому GPU encoder обоснован только после проверки качества и предсжатого аппаратного пути.

## Малый опыт A: что именно делает ошибку V вредной

Статус этой постановки: **Запланировано**. Выполнение и данные сохраняет основной экспериментальный поток. Используются только существующие `story.npz` и `v_decoded.f32` из `story_l17_v_token6`/`story_l17_kv_page6`. Выбор story/layer17 вынужден наличием обеих декодированных fixtures, а не просмотром нового результата. Это exploratory-механизм, не новая holdout-серия.

Гипотеза: разницу attention error между token6/page6 частично создаёт согласованность ошибок V по токенам, а не только суммарный MSE. K нужно оставить одинаковым в обоих вариантах: использовать общий FP16 K для вычисления P, а не K из page6 fixture, где он тоже сжат. Q берётся из capture, GQA соответствует исходной модели.

Для каждого причинного запроса 288…383 и каждой Q-головы вычисляются FP64 reference и P. Сжимается только префикс 0…287, хвост общий; fourth encoded fixture page в опыт не входит. Это избегает использования диапазона незавершённой страницы для ранних запросов. При фиксированном P равенство `ΔO=P·E` точное, не линеаризация, где `E=V_decoded−V_original`.

Контроли:

1. Исходная E и обычный U4 token, включая одинаковую обработку FP16 хвоста.
2. Независимые знаки `s_t=±1` на строках E. Каждая норма `||e_t||²` сохраняется точно. Для ошибки только сжатого префикса аналитически `E_s ||Σ p_t s_t e_t||² = Σ p_t² ||e_t||²`. Разность с исходной энергией — суммарный off-diagonal вклад, который может быть отрицательным. 128/256 фиксированных seeded реализаций проверяют формулу и дают диагностический reference distribution, не CI переносимости на документы.
3. Перестановка строк E внутри каждой 96-token страницы. Сохраняются page histogram, средний вектор и суммарный MSE, но меняется привязка ошибки к P и исходному token; это вмешательство в ошибку, не новый ASTC encoder/layout.
4. `E=B+R`, где B повторяет средний вектор ошибки страницы. Публикуются `||PB||²`, `||PR||²`, cross-term `2<PB,PR>` и сумма. Эти члены нельзя объявлять независимыми долями без cross-term.
5. Поправка после decode `V'=V_decoded−FP16(mean_page(E))`. Она использует только завершённую страницу и её reconstruction, поэтому не требует будущих Q; но требует вычисления reconstruction при кодировании и отдельного runtime metadata. Точный неокруглённый mean служит дополнительным численным контролем, не бесплатным форматом.

Для всех контролей нужно отдельно показывать ошибку относительно общей V baseline и итоговое внимание относительно FP32. Иначе ошибка K/хвоста скрыто попадает в объяснение V. Проверки: конечность, маска, корректное GQA, identity при E=0, точное сохранение row norms под знаками, совпадение прямого recompute с P·E, равенство energy decomposition.

Предсказание H2a: исходная attention error устойчиво выше sign-null при том же row-wise MSE; page mean correction уменьшает её. Отрицательный результат: исходная энергия не выше null либо correction не помогает/вредит. В таком случае «согласованный bias» не объясняет наблюдение в этой fixture; нельзя автоматически переходить к сложному корректору. Положительный исход обосновывает следующий опыт на новых документах/слоях, но не доказывает качество модели и новизну.

Бюджет: один слой, один документ, две ASTC реконструкции, 9 Q-голов, 96 запросов, 3 страницы; не скачивать веса/encoder, не подбирать параметры после результата. Нет статистически независимых 864 запросов: все они принадлежат одному документу.

## Малый опыт B: полезна ли коррекция при честном бюджете

Это условное продолжение A, не повод заранее писать GPU encoder. Один FP16 bias на канал каждой 96-token страницы требует `16/96=0.1666667` bit/V. Для scalar6 token D64 итог `4.1666667+0.1666667=4.3333333` bit/V, против U4 token `4.5`; пара scale+bias стоила бы вдвое больше. Padding ASTC уже включён в 4.1667. Для префикса 288, Hkv=3, D=64 одна correction table — 1152 байта. Таблицы режима, выделение Metal и scratch считаются дополнительно.

Зафиксированный кандидат — только FP16 page mean subtraction, без выбора alpha или слоёв по текущим queries. Сравнить с U4 token на тех же K, хвосте и queries, затем с одинаковой поправкой U4: иначе улучшение может оказаться общим свойством коррекции любого квантования. Если corrected ASTC остаётся хуже U4 либо коррекция U4 уничтожает преимущество, это отрицательный исход для данного кандидата. До новых captures и полного causal rollout результат ограничен одной диагностической fixture.

Возможный исследовательский вклад здесь — подтверждённая связь конкретных ASTC modes/нормализации с корреляционной структурой ошибки и дешёвым действием, которое улучшает качество/память/время. Формула P·E, mean subtraction и низкоранговое исправление сами по себе известны и не должны называться открытием.
