## Контракт опыта

Используется V-префикс 288 токенов, scalar LDR ASTC6×6, качество98. FP16 offset/scale вычисляются один раз на исходный токен, как в `encode_tensor` с `normalization=token`. Нормализованный D64 дополняется edge padding до D66. Затем одинаковая статическая перестановка применяется к каждому из 6×6 блоков; после decode она обращается, padding удаляется и исходные ranges применяются к исходным токенам. Таким образом сохраняются состав каждого блока и все ranges. Изменяется только расположение значений внутри блока. Q, K и ошибки не участвуют в выборе перестановки.

Заранее выбран полный набор восьми симметрий квадрата D4: identity, три поворота, два отражения, transpose и anti-transpose. Дополнительно включены одна seed-фиксированная перестановка36 значений и отрицательный контроль перемещения целых блоков внутри head с обратной перестановкой. Seed20261028; отдельный whole-block map использует seed+1. Никаких индивидуальных подборов ориентации блоков или отбора вариантов после первого слоя нет.

Негативные критерии: обратимость всех maps и сохранение multiset; identity обязан точно совпасть по payload, decode и byte count с существующим codec; whole-block permutation после inverse обязан точно совпасть с identity по payload и decode. Нефинитные значения или нарушение контроля останавливают интерпретацию качества и расширение.

Первый запуск — story/layer17. Если все контроли прошли и wall time≤30s, выполняются остальные23 пары (четыре capture×шесть слоёв). Расширение зависит только от корректности и времени. Общий бюджет180s, проверяемый между парами. Один CPU-процесс, OPENBLAS_NUM_THREADS=1 и VECLIB_MAXIMUM_THREADS=1. GPU не используется.

## Метрики и границы

Основная метрика изолирует ошибку V при неизменных оригинальных Q/K и полном causal FP64 softmax: ΔO=P_prefix(V_decoded−V). Веса префикса не перенормируются. GQA отображает query heads на соответствующие KV heads. Aggregate relative L2 вычисляется из сумм SSE, а не усреднением relative L2 строк. Также сохраняются tensor SSE/relative L2/MSE, ошибка нормализованных padded блоков, и практическая V-only ошибка с FP16 K и FP16 tail против оригинального FP64 reference.

Для каждого 16-byte payload фиксируются 11-битный block-mode identifier и число partitions; расположение полей проверено по `third_party/astc-encoder-5.7.0/Source/astcenc_symbolic_physical.cpp` (write_bits на строках200–201 и read_bits на301,390). Ошибки группируются по режимам. Эти описательные связи не доказывают, что конкретный mode причинно лучше: encoder выбирает его по данным. Настройки encoder mode search не меняются.

У D4 нет metadata на cache: выбор глобально фиксированной ориентации реализуется координатной арифметикой. Payload и FP16 ranges имеют тот же размер. Для random36 отдельно учитываются36bytes фиксированной uint8 map; для whole-block контроля — uint16 map, общая для heads. Эти два диагностических варианта не выдаются за кандидаты с тем же cache bit budget. Стоимость GPU addressing и его влияния на доступ к памяти не измеряется.

Любой лучший D4 после опыта — кандидат для следующей независимой замороженной проверки. Этот опыт сам по себе не даёт model PPL, runtime-ускорения или новизны. Пространственная чувствительность ASTC и перестановки blocks уже известны; проверяется полезность конкретного статического layout для этих KV-данных.

## Артефакты и проверка

`configs/block_geometry_v2.json` задаёт варианты, seed, бюджеты и критерии до запуска. `scripts/probe_block_geometry.py` сохраняет новые normalized fixtures, исходные metadata, payloads, реконструкции, raw rows, агрегаты и hashes источников/библиотеки/captures только в новом `results/block_geometry_v2/`. Исходные fixtures и предыдущие результаты не перезаписываются. Для whole-block контроля дополнительно сохраняется encoded-order payload до обратной перестановки.

Самопроверка без кодирования:

```sh
env OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 .venv-research/bin/python scripts/probe_block_geometry.py --self-test-only
```

Результат: PASS — split/join, обратимость9 maps, восемь различных D4 maps, multiset, whole-block inverse, causal/GQA, parser headers. Полный запуск выполнен после согласованного CPU-окна:

```sh
env OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 .venv-research/bin/python scripts/probe_block_geometry.py
```

Результат: PASS,24pairs/240rows, остановка `complete`; библиотека, исходники, config и captures не изменились. Повторный запуск по тому же пути отказался бы перезаписать результат; для отдельного повторения требуется новый `--out`.

Независимая stdlib-проверка заново суммировала raw rows через `math.fsum`: 110 aggregate groups совпали, mode/partition counts и суммы ошибок сошлись, payload hashes совпали, identity/whole-block `.bin` и `.npy` совпали побайтно во всех 24 парах. Память независимо подтверждена как 28800 bytes во всех строках. Результат: `results/block_geometry_v2/independent_validation.json`. Проверка сохранённых результатов повторяется без encoder и без перезаписи файлов:
