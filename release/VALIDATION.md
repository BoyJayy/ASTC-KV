# Проверка подготовки

Дата: 2026-10-29. Проверена отдельная экспортная копия. Исходная рабочая папка не изменена. Эта проверка относится к подготовке пакета, а не к новому исследованию скорости.

| Проверка | Команда | Результат |
|---|---|---|
| Состав, размеры и известные шаблоны секретов | `python3 tools/verify_snapshot.py --scan-only` | PASS |
| Пересчет сохраненных v8/v9/v10 | `python3 tools/check_results.py` | PASS: 72 процесса, 1008 проверок, 6600 блоков, 26400 записей времени |
| Тесты без native bridge | `python tools/run_unit_tests.py` | 31 PASS, 1 SKIPPED |
| Чистая сборка CPU bridge | `bash scripts/build_codec.sh` | PASS |
| Тесты с заново собранным bridge | `python tools/run_unit_tests.py --with-codec` | 32 PASS, 0 SKIPPED |
| Сборка последнего Metal host | `bash metal/build_gqa_v10.sh` | PASS |
| Offline Metal shader compilation | Шаг внутри `metal/build_gqa_v10.sh` | SKIPPED: offline compiler недоступен |
| Новый GPU-запуск и повторные замеры | Не запускались | SKIPPED: подготовка архива, результаты уже сохранены |
| Исходный frozen snapshot | `python scripts/freeze_research_v4.py --verify`, в исходной папке | PASS: v4 269 файлов и 3 binaries; предыдущий v3 218 файлов и 2 binaries |

Для CPU-сборки и полного теста создана еще одна временная копия экспорта. В нее подключен уже имеющийся astc-encoder 5.7.0; новые зависимости не скачивались и в систему не устанавливались. Сборка создана с нуля в этой копии. Использован прежний Python 3.12.14 с NumPy 2.3.5, CMake 3.31.6 через переменную `PYTHON`, AppleClang 21.0.0. Переносимые проверки дополнительно выполнены системным Python 3.15.1.

Проверка синтаксиса через `ast.parse` прошла для 57 Python-файлов. `bash -n` прошел для всех 17 shell scripts. Ссылки в документах корня и итоговом отчете v4 ведут к существующим локальным файлам. Новые документы и пять основных исследовательских отчетов не содержат декоративной пунктуации. Исторические копии и исходная постановка сохранены как архивные материалы.

Отдельное сравнение с исходной папкой подтвердило неизменность всех 2330 исходных файлов, использованных для экспорта, по заранее записанным SHA256. Все 1261 численных/бинарных файлов данных перенесены побитно. В 557 JSON проверены одинаковые структуры и численные значения с учетом замены личных путей в строках и ключах. Никакие измерения не корректировались при упаковке.

Первый вспомогательный проход сравнения JSON остановился на ключах с замененными путями. После учета этой документированной замены сравнение прошло. Это исправление проверки экспорта, данные измерений не менялись.

Отрицательные performance-результаты остаются FAIL: gather, exchange и GQA не прошли свои заранее заданные критерии. PASS пересчета означает совпадение с сохраненными выводами, а не ускорение ASTC.

После подготовки список файлов запечатывается в `release/manifest.json`. Целостность проверяется командой `python3 tools/verify_snapshot.py`. Проверки готового ZIP, распаковки и обнаружения измененного файла записываются рядом с выдаваемым архивом в `DELIVERY_CHECK.json`, чтобы не менять уже запечатанные файлы.

Проверка по известным шаблонам не является гарантией обнаружения любой чувствительной информации. Нового полного модельного прогона, CI в GitHub и публикации не выполнялось.

После подготовки та же версия перенесена в основную папку проекта `astc-kv`. До переноса сделана отдельная локальная резервная копия исходных файлов и frozen binaries; в ней `python scripts/freeze_research_v4.py --verify` прошел для v4 и v3. История Git, зависимости и окружение основной папки сохранены. Исторические исполняемые файлы дополнительно исключены через `.gitignore`. Для текущей версии используется публичный манифест; старые frozen-проверки выполняются в резервной копии.

Затем по запросу пользователя файлы подняты из `astc-kv/` прямо в корень проекта. Существующий корневой Git-репозиторий, его ветка `main` и `origin` сохранены. Прежняя вложенная история Git и старый корневой README сохранены в локальной резервной копии. Оставшийся каталог `astc-kv/` содержит только локальные зависимости, окружение и старые сборки; он исключен из Git целиком. Окружение и зависимости доступны через игнорируемые локальные ссылки. Перед локальным коммитом повторяются `python3 tools/verify_snapshot.py`, `python3 tools/check_results.py`, `.venv-research/bin/python tools/run_unit_tests.py --with-codec` и сравнение `git ls-files --cached --others --exclude-standard -z` с публичным манифестом. Новые GPU-измерения и отправка на GitHub не выполняются.
