# ASTC-KV

Исследование KV-кэша с аппаратным ASTC-декодированием на Apple GPU. Завершающий исследовательский снимок от 2026-10-29. Оригинальный код распространяется под [MIT](LICENSE).

**Это архив исследования. Преимущество полного inference и научная новизна не установлены.** Здесь сохранены работающие прототипы, проверки, исходные измерения и отрицательные результаты. Динамический GPU-кодировщик и рабочий runtime с обновлением кэша не реализованы.

## Основные результаты

- Прямое чтение ASTC в Metal attention выполнено и проверено на Apple M5 Pro.
- На T8192 компактный ASTC V + FP16 K занимал 3981312 bytes постоянной KV-памяти против 6291456 bytes FP16 K/V: экономия 36.72%. Это не пик памяти процесса и не выигрыш качества или времени.
- Начальный собственный прототип удалось значительно ускорить. Более сильные сравнения не подтвердили преимущество ASTC над FP16 и обычными low-bit подходами.
- Последний цикл проверил gather, обмен значениями между потоками и совместное GQA: 72 GPU-процесса, 1008 успешных проверок attention, 26400 основных записей времени. Все три заранее заданных performance-критерия не пройдены.

T384 - реальный snapshot одной модели. T2048/T8192 в последних kernel-опытах повторяют его блоки и не являются новыми модельными тестами длинного контекста. Проверка вычислений относительно одинаковых восстановленных значений не означает отсутствие потерь ASTC относительно исходного KV.

## Быстрая проверка сохраненных результатов

Python 3.12+, без GPU, модели и сторонних Python-пакетов:

```sh
python3 tools/verify_snapshot.py
python3 tools/check_results.py
```

Для численных unit tests нужен NumPy:

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install numpy==2.3.5
python tools/run_unit_tests.py
```

Без native bridge один настоящий ASTC roundtrip явно пропускается. Сборка bridge и запуск всех тестов описаны в [REPRODUCIBILITY.md](REPRODUCIBILITY.md). Новая аппаратная серия требует Apple Silicon, Command Line Tools и разрешенного доступа к Metal.

## Состав

```text
astc_kv/       CPU bridge, представления и численные метрики
metal/         Metal shaders и Objective-C++ hosts всех версий
baselines/     адаптер к зафиксированному llama.cpp
configs/       протоколы, записанные до измерений
data/          исходные диагностические тексты
fixtures/      дополнительные тексты и token IDs
tests/         тесты чисел, адресов, GQA и протокола измерений
scripts/       capture, эксперименты, сборка, старые локальные проверки
tools/         переносимые проверки этого публичного снимка
results/       все сохраненные данные, captures и сырые измерения
docs/          отчеты, спецификация и prior art
release/       манифест экспорта, контрольные суммы и проверка подготовки
licenses/      notices сторонних компонентов
```

Веса, скачанные зависимости, виртуальные окружения, Git history и локальные бинарники не включены. Пути рабочей станции в текстовых артефактах заменены общими примерами; численные массивы и результаты не пересчитаны. Изменения и связь с исходными hashes записаны в `release/source_export.json`.

Исторические manifests и некоторые проверки в `scripts/` относятся к исходной рабочей станции. Для этого экспортированного пакета используйте `tools/verify_snapshot.py`. SHA256 публичных файлов хранит `release/manifest.json`. `.gitattributes` отключает изменение окончаний строк, чтобы Git сохранял эти байты.
